# Premier League Stadium Guide

A four-page website covering all twenty stadiums in the 2026-27 Premier League. Built for the AI-Assisted Coding "Personal Interest Website with an LLM" project at UW-Stout.

## Pages

- `index.html` - Home: intro, league numbers, three featured grounds
- `grounds.html` - All twenty grounds with search, region filter and sorting
- `gallery.html` - Photo grid with a lightbox viewer
- `about.html` - About, expandable FAQ and image credits

## Structure

```
index.html  grounds.html  gallery.html  about.html
css/style.css        shared stylesheet
js/script.js         shared script (stadium data and all interactive features)
js/credits.js        photo credits, generated by the script below
images/              one photo per stadium, named <slug>.jpg
tools/fetch_images.py
```

## Getting the photos

The photos are not written by hand. Run this once from the project folder:

```
python tools/fetch_images.py
```

It downloads the lead photo of each stadium's Wikipedia article from Wikimedia Commons into `images/` and writes each photo's author and license into `js/credits.js`, which the About page displays.

## Interactive features

- Dark/light mode toggle, remembered with `localStorage`
- Search, filter and sort on the Grounds page
- Gallery lightbox with keyboard controls (arrow keys, Escape)
- Expandable FAQ
- Collapsible navigation menu on phone-sized screens
